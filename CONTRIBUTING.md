# Contributing

Report reproducible problems through the GitHub issue templates. Include the resource version, WHIP dependency versions, expected/actual behaviour and relevant sanitised logs. Do not attach live `data/doorbells.json`, personal identifiers, screenshots of private RP or server credentials.

For changes, work on a separate branch, keep the WHIP-only integration and preserve existing inventory/camera/voice behaviour. Prefer bounded event payloads and avoid unnecessary frame loops. Update the changelog and relevant docs. Run the static checks and the relevant [in-game checks](docs/TESTING.md) before submitting a pull request.

Contribute only code and assets you have permission to share. The repository's redistribution terms must be confirmed by the maintainer before public publication.
